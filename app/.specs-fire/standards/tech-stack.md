# Tech Stack — app/

**Package**: rastroapp
**Type**: Mobile App

## Core

- **Framework**: Expo SDK 54 (React Native 0.81)
- **Language**: TypeScript (strict mode)
- **Navigation**: Expo Router 6 (file-based routing)
- **Path Alias**: `@/*` → root
- **Package Manager**: pnpm

## UI / Maps

- **Maps**: react-native-maps 1.20.1 (Google Maps)
- **Animation**: react-native-reanimated 4.x
- **Gesture**: react-native-gesture-handler 2.x

## Storage

- **Local Storage**: AsyncStorage 2.2.0 (multi-account user management)

## Development

- **Dev**: Expo dev server
- **Build**: EAS Build (Android APK, internal distribution)
- **Linter**: ESLint 9 (eslint-config-expo)
- **Env Loading**: dotenv (via app.config.js)

## Commands

| Command | Action |
|---------|--------|
| `pnpm start` | Start Expo dev server |
| `pnpm android` | Run on Android |
| `pnpm ios` | Run on iOS (macOS only) |
| `pnpm web` | Run in browser |
| `pnpm build:android` | EAS build APK |
| `pnpm lint` | ESLint check |

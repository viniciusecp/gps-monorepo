# Implementation Walkthrough: Integração com Nominatim Reverse Geocoding

## Summary

Integração da API Nominatim OpenStreetMap Reverse Geocoding no backend (serviço + rota) e no app (exibição do endereço ao clicar em coordenada), seguindo a arquitetura existente de services/controllers/routes.

## Structure Overview

- **Backend**: Novo `NominatimService` em `server/src/services/geocode/` (fetch nativo, env vars, timeout). Controller + rota em `controllers/` e `routes/`. Serviço decorado no Fastify instance.
- **Frontend**: `map.tsx` atualizado para buscar `display_name` via `useEffect` e exibir em card sobreposto ao `MapView`.

## Architecture

### Pattern Used
Proxy pattern — app chama o próprio backend, que faz proxy para a Nominatim API. Isso esconde a API pública do cliente e permite controle centralizado.

### Layer Structure
```text
┌─────────────────────────────┐
│   app/app/map.tsx           │  ← React Native
├─────────────────────────────┤
│   GET /api/geocode/reverse  │  ← Fastify Route (server)
├─────────────────────────────┤
│   geocode-controller.ts     │  ← Controller
├─────────────────────────────┤
│   NominatimService          │  ← Service (fetch externo)
├─────────────────────────────┤
│   api.openstreetmap.org     │  ← Nominatim API
└─────────────────────────────┘
```

## Key Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Proxy via backend vs chamada direta | Backend proxy | Esconde API key futura, controle de rate limit centralizado |
| Rota sem autenticação | Sem auth | Dados públicos da Nominatim, evita complexidade |
| Timeout | 10s | Nominatim é rápida, evita espera longa em caso de falha |
| User-Agent | "GPS-Monorepo/1.0 (mobile-app)" | Obrigatório pela ToS da Nominatim |
| Card overlay vs modal | Card semitransparente | Não bloqueia interação com o mapa |

## Developer Notes

- Nominatim tem rate limit de 1 requisição por segundo. Uso intenso pode precisar de cache no futuro.
- O User-Agent header é obrigatório pela política de uso da Nominatim. Qualquer modificação deve mantê-lo.
- Se a API retornar `{ error: "Unable to geocode" }`, o serviço lança erro que é propagado como 500.

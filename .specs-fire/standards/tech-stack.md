# Tech Stack

## Overview

Monorepo with two TypeScript packages: a Fastify REST API backend with Drizzle ORM + MySQL, and an Expo React Native mobile app.

## Server (gps-api)

### Language

**Primary**: TypeScript
**Version**: ES2022

### Framework

**Framework**: Fastify
**Version**: 5.3.3
**Runtime**: Node.js

### Data Layer

**Database**: MySQL
**ORM**: Drizzle ORM 0.44.2 (mysql2 driver)
**Caching**: Not configured.

### API Style

**Style**: REST (routes → controllers → services → repositories)

### Auth

**Auth**: JWT (15min access token, 365d refresh token), MD5 password hashing

## App (rastroapp)

### UI Framework

**Framework**: Expo SDK 54 (React Native 0.81)
**Navigation**: Expo Router 6 (file-based routing)
**Maps**: react-native-maps with Google Maps

### State Management

**Storage**: AsyncStorage for user accounts
**Context**: React Context (ErrorPopupContext)

## Development Tools

### Package Manager

**Manager**: pnpm (workspace monorepo)

### Linting

**Server**: Biome 2.14 (tabs, double quotes)
**App**: ESLint 9 (eslint-config-expo)

### Formatter

**Server**: Biome (tabs, double quotes)
**App**: ESLint (via eslint-config-expo)
